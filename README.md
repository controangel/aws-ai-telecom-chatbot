# AI Telecom FAQ Chatbot

## Overview
A beginner AI chatbot built using Amazon Lex to answer telecom support questions.

## AWS Services Used
- Amazon Lex
- AWS IAM

## Features
- Device Offline Troubleshooting
- IMSI Rotation Explanation
- High Data Usage Support
- Purge Event Support

## Sample Questions
- Why is my device offline?
- What is IMSI rotation?
- Why is my data usage high?

## Architecture

User -> Amazon Lex -> FAQ Response
